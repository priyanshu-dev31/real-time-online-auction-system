# Real-Time Online Auction System

A web-based auction platform developed as a BCA major project using Flask, MySQL, HTML, CSS, JavaScript, and AJAX polling.

## Features

- User registration and login
- Role-based user and admin access
- Create, edit, and delete auctions
- Search, filter, and sort auctions
- Product image upload and image URL support
- Live price and bid-history updates using AJAX polling
- Automatic auction closing
- Winner declaration
- User bid history
- Admin dashboard
- Responsive interface
- Custom 404 and 500 error pages

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- MySQL
- PyMySQL
- HTML
- CSS
- JavaScript
- AJAX
- Jinja2
